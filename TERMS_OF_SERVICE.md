## 2. About the Bot

**fivemsorgu** is a Discord bot that provides real-time FiveM game server information using FiveM's publicly available API. The Bot allows users to query information about players currently connected to specific FiveM servers.

- **Support Server:** [discord.gg/erenlol](https://discord.gg/erenlol)
- **Bot Name:** fivemsorgu
- **Developer:** Available via the support server above

## 3. Description of Services

The Bot provides the following slash commands:

| Command | Description |
|---|---|
| `/id` | Queries a player's live information by their in-game server ID |
| `/tag` | Lists all active players whose names start with a given tag/prefix |
| `/name` | Searches for active players by name across all tracked servers |
| `/playerlist` | Displays the live player list of a selected FiveM server |
| `/id-data` | Retrieves historical snapshot data of a player by their server ID |
| `/data-ara` | Searches the database for player records by name |
| `/istatistik` | Shows bot usage statistics (restricted to the bot owner) |

All player data is sourced from **FiveM's public API** (`servers-frontend.fivem.net`). The Bot does not access any private or non-public data sources.
